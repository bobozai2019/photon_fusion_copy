# 执行状态

本阶段的 `verify_plates.py` 混合引擎实验用于诊断公共 Core。产品验收按引擎分别组房，复跑同引擎玩法时在 `examples` 仓执行 `python -B tools/verify_gameplay_components.py --engine godot`，也可选择 `unity` 或 `cocos`。[运行器](../../../examples/tools/verify_gameplay_components.py)

13/13 项已通过约定的本地验收。环境是 Windows x64 同机的玩家房主和客户端。以 [13 项执行计划](执行计划.md) 为准。实际运行命令和观测值见[验收记录](验收/记录.md)。

|---|---|---|

| 2 | 按对象的客户端写权 | 两名客人分别持权；同物争抢、拒绝、过期、释放、掉线、随房主迁移都有断言 |
