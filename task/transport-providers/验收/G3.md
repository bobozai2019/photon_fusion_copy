# G3 · 安装包与二进制替换

Godot 导出器把 TCP DLL 写在 Player 同目录，Unity 把 TCP DLL 写进 Player 的原生插件目录，Cocos 验收工程把 DLL 随宿主部署。三端实际报告 `tcp/de784fb21cfe665a/v1` 与 `example-pipe/win-pipe-message-v1/v1`。缺 DLL 返回带路径的加载错误，错误 ABI 返回 `ABI v1 negotiation failed (unsupported_abi)`。三端最终消费测试退出码均为 0，日志位于 `out/runs/transport/g3-{godot,unity,cocos}.log`。

Cocos 消费者从两个独立解压的 SDK ZIP 编译。宿主导入已有 Cocos x64 无窗口引擎的 Release 库，开启 2D 和 3D 物理。vcpkg 在本 worktree 复建缺少的依赖，注册表版本为 `1460b31b08c42cc2e9ac2c79f45ec8707e2675e2`，宿主目标记录在 `out/tmp/cocos-ports/CocosHostTargets.cmake`。

用 `tests/transport/verify_players.py` 启动。外部 DLL 由 `tests/transport/external/` 复制到独立源码目录后生成，构建只包含安装后的传输头文件和 Windows 系统 API。
