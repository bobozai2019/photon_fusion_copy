# G1 · 传输契约和实现

Windows x64 Release，MSVC 19.51.36260.0。C ABI 在 `4587fd8` 冻结，TCP 实现在 `b0bc4a1`，外部夹具在 `760cabe`，Direct ABI 在 `1bb67c5`。TCP 的构建标识为 `de784fb21cfe665a`，Direct 为 `c8e3f480050b0cfe`，外部样例为 `win-pipe-message-v1`。

| 入口 | 实测结果 | 退出码 |

外部命名管道样例只接受本机对端。它验证独立实现和真实 Windows 进程间通路。TCP 和 Direct 的 IP 数据路径另有回环和 SDK 消费验证。

`40882ca` 的 TCP 轮询预算修订在独立 DLL 构建 `485c3aad85fed594` 上重跑通过。新增用例验证一次轮询发送 48 KiB，并在 TCP 流中保留所有帧边界和字节。日志为 `out/runs/transport/g4-tcp-drain-contract.log`，内存夹具日志为 `out/runs/transport/g1-memory-contract.log`。
