# M3 · 双窗口可玩车场

2026-11-20，Windows x64，两个 Cocos 4 窗口操控各自车辆。Release、Intel UHD Graphics 630、OpenGL 4.6。

```powershell
& ./out/build/win-x64/Release/bin/Release/netcode-yard.exe --binding-smoke
python -B tools/verify_yard.py play --port 43221 --capture
```

| 栏位 | 实测 |
| --- | --- |
| 原版实测 | Godot Racing 通过节点路径声明本地字段，布局证据见 [M0](M0.md)。 |
| 自研实测 | Cocos 测试比较 2D 的两轴位置、旋转、两轴缩放与 3D 的三轴位置、旋转、缩放。单改根字段后子节点值保持，移除并重建同名子节点后正确绑定。动态实例销毁后对应 ID 的节点移除。两个进程均退出 0。 |
| 双方对照 | 两个适配器都通过节点路径绑定字段。Cocos 从 `replicators.cfg` 定义跨端字段和变换预设，自研核心按 schema 编码。 |

B 的对象 2 在同一帧从显示 X=237 移到 237.169，当时权威快照 X=238.015。房主和客人的车辆 ID 分别为 1 和 2。最终两端都有 5 个对象，完整 ID、模板、所属和字段摘要一致。捕获画面中闸门已开，客人车前有动态路障，右侧为 Sprite3D 网格。[车场画面](M3/车场.png)

可玩键位和双开命令见[样例说明](../../../examples/car-yard/README.md)。
