## Windows x64 包

在 `out/packages/win-x64/current/` 生成 ZIP 和 SHA-256 清单。包内含两个 x64 程序、配置、网格、玩法说明与第三方许可。两程序静态链接 MSVC 运行库，PE 依赖仅为 Windows 系统库。对解压产物执行窗口冒烟、2D/3D 绑定回归和双窗口联机。包内场景的客人恢复用时 1233 ms，含 1050 ms 的预设离线时间，最终两端均为 5 对象，摘要为 `6700638356016534761`。所有命令退出 0。

ZIP 大小为 1705750 字节，SHA-256 为 `d6f7f8d6ff1b0ad0afcea16bd1bde01d57a71013b2700ab4d12cc54bded475d1`。已逐字节核对包内程序和资源与当前构建一致。重复打包得到同一摘要，当前槽保持。轮换回归检查新包推进前一槽，并在模拟发布失败时恢复当前和前一槽。原始双窗口证据轮换至 `out/runs/last-pass/`。[可玩步骤](../../../../examples/yard/shared/README.md)

### 三引擎与故障进程复验

三个前端各以房主、客人开两个真实窗口，运行 `python -B tools/verify_yard.py play --platform <平台> --typed-profile`，再用 `--authority` 运行委托场景。每项均检查房间、两种传输通道、实际节点上的本地运动与远车显示、原车重连、最终摘要以及双方正常退出。类型化用例另读回超过 float 精确整数范围的分数 16777217，开门后更新为 16777219，节点名称或对应属性更新为“通关”，物品列表从三项变成一项，浮点列表清空。以下恢复时间包含脚本设定的 1050 ms 离线间隔。

| 平台 | 房主预测和类型化配置，客人恢复时间 | 客人写权，提交数 / 房主接纳数 | 客人写权，重连恢复时间 |
| --- | ---: | ---: | ---: |
| Cocos2d-x | 1226 ms | 135 / 87 | 1200 ms |
| Godot 4.7.1 | 1200 ms | 133 / 86 | 1183 ms |
| Unity 6000.4.0f1 | 1169 ms | 132 / 85 | 1283 ms |

Godot 房主与 Unity 客人额外运行 `python -B tools/verify_yard.py play --platform godot --guest-platform unity --typed-profile --fault --port 43407`。共丢弃 24 包、复制 39 包、乱序 33 包。Unity 实际节点在权威公开 x 为 218.520 时显示 x 为 215.417，同时本车读到本地预测。重连耗时 1232 ms，双方最终摘要为 `15999385574113464827`。一次 Unity 冷启动和一次引擎退出超时暴露了验证脚本的固定等待限制。脚本现分别等待 Windows Player 初始化、引擎退出，继续要求退出码为 0。最终 Unity 同引擎两个进程的摘要均为 `13638471662691257910`。

| 四人百对象，各运行 10 秒 | 模拟步 / 发送批次 | 丢弃 / 复制 / 乱序 | 结果 |
| --- | ---: | ---: | --- |
| 房主结算所有车辆 | 300 / 200 | 184 / 256 / 229 | 四端摘要 `12918851976728775203`，观察到实际本车预测和代理插值 |
| 两位客人持权，另外两辆车由房主写 | 300 / 200 | 182 / 254 / 230 | 提交 557 次，房主接纳 350 次，玩家 2 断线接管后以新代次返回，恢复 1200 ms。四端摘要 `12888389160139469938` |

两个场景都包含 4 辆车、门、信标与 94 个负载对象。复现命令为 `python -B tools/verify_yard.py stress --platform cocos2dx --fault --seconds 10`，混合写权版本追加 `--authority`。本轮共通过六组同引擎双窗口、一个故障跨引擎双窗口、两组四人百对象。新构建直接位于 `out/build/win-x64/Release/bin/Release/`。房主离开结束本局，原生多刚体求解器和关节回滚另行验收。

Cocos2d-x 和 Godot 的 `--binding-smoke` 也均以 0 退出，分别读回 2D/3D 变换、独立字段、子节点替换及删除结果。
