# M1 · 独立连接与房间

2026-11-20，Windows x64，真实进程使用回环端口 43216 和 43217。

当前从 `netcode` 仓根目录复跑相同的进程用例。以下使用 Release 配置，表中保留首次验收的结果。

```powershell
python -B tools/build.py core --config Release
python -B tests/integration/room_processes.py out/build/win-x64/sdk/core/Release/tests/Release/room_probe.exe --port 43216
```

| 栏位 | 实测 |
| --- | --- |
| 原版实测 | 指定 Fusion Linux 插件有 Notify 通道及 ACK 符号。 |
| 自研实测 | 内存连接与 Winsock 共用房间状态机。错房请求拒绝，B 以玩家 2 在同一房间进入第 1、2 局，首局中新成员拒绝。主动关闭通知 B 房间结束。房主停泵时，B 按 1200 ms 测试阈值进入 Timeout。所有子进程退出 0。 |
| 双方对照 | 参照 Fusion Notify 的投递职责。TCP 房间帧、独立 UDP 游戏报文和房主退出行为由项目定义。跨局包拒绝见 [M5](M5.md)。 |

错房和锁员请求会收到明确原因，随后连接关闭。脚本在所给端口运行两局场景，在下一端口运行超时场景。
