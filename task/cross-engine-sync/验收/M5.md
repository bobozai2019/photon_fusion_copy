# M5 · 断线续玩

本页保留里程碑当时的命令和指标。当前 `tools/verify_yard.py` 与车场构建产物位于同级 `examples` 仓；从该仓根目录运行示例。支持的房主与客人组合见[同引擎验收表](../../../docs/roadmap.md)。

2026-11-20，Windows x64。真实窗口场景 `python -B tools/verify_yard.py play --port 43221 --capture` 和独立 `match` 回归均退出 0。

| 栏位 | 实测 |
| --- | --- |
| 原版实测 | Fusion Core 公开文档中的完整对象状态用于兴趣区进入。 |
| 自研实测 | B 以玩家 2、车辆 2 入局。断开后车 2 输入从 0.75 归零。房主开车、创建并移除路障 6，再创建路障 7。B 在 1249 ms 内恢复玩家 2、车辆 2，用时含 1050 ms 的预设离线窗口。B 的 −0.5 重新驱动房主车辆 2。恢复后双方 5 个对象，摘要相同。 |
| 双方对照 | 使用完整当前对象状态建立接受输入前的基线。保留席位、车辆惯性和旧包失效按项目契约。 |

内存回归检查锁员、错误凭证、重复恢复、离线车辆继续移动。基线排除已销毁路障并包含新增路障。第二局开始后向现用连接投递第一局输入，不能覆盖新局车辆。第一局凭证也无法恢复第二局玩家。Windows 后端在每次连接时更换随机 TCP/UDP 关联值。
