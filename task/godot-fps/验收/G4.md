# G4 双端画面

2026-11-22，Windows 10 x64，GTX 1050，Godot 4.7.1 Compatibility。可视窗口中用正式角色和两套队色重现双视角换弹。场景走法和对局状态见 [G2](G2.md) 与 [G3](G3.md)。

```powershell
python -B tools/verify_godot_fps.py --suite gameplay --visible
```

本机能看到蒙皮手臂、步枪和换弹动作。旁观端显示整身队色角色及同步的换弹动作，阵亡切到 `Death`，复活呈现新生命状态。弹药 HUD、有效命中标记、曳光、离手后的飞行模型和爆炸使用各端的状态与一次性事件。

长时间运行时，第一人称腕部求解曾反复写回全局骨骼矩阵，在长时间开房和补位重开路径上出现比例误差。腕部现以父骨骼坐标计算并只写旋转，骨长和缩放按资源原值运行。复测包含满员后补位、重开和整场动作。

可视全套复跑退出码 0，各进程 Godot 错误数为 0。后续统一了碎木、补给和墙板的材质色板，Windows 包启动和全套状态复验通过。[破箱状态](G3/broken-crate.png)

## 持枪、换弹与停火复查

从射手和旁观者两个可视客户端驱动正常输入。探针将两人移到可互相观察的位置，移动、开火和换弹均通过游戏输入路径执行。

```powershell
python -B tools/verify_godot_fps.py --suite motion --visible
```

| 现象 | 定位与修复 | 双端复验 |
| --- | --- | --- |
| 第一人称左袖附近有细长尖刺 | 尖端顶点同时受肩与上臂绑定影响。将袖口着色移到蒙皮网格，袖内顶点随上臂运动，调整镜头中的手臂根位置和左肘弯曲方向。 | 待命、开火和拆装弹匣截帧均见连续的左前臂和袖口。换弹时左手从枪旁取出弹匣，插回后弹药恢复至 30 发，再开火降至 29 发。 |
| 近处枪口闪光盖住握枪的手 | 本机同时收到世界闪光和枪模闪光。将本机闪光挂到枪管前端，世界曳光从枪模前方开始显示。 | 开火可见枪模后坐，松开扳机后后坐值和闪光恢复为零。 |
| 旁观者看到角色持枪动作，枪却藏到手臂附近 | 独立步枪模型与角色自带步枪的朝向相差 180°，比例相差约 2.39 倍。换算至原有指骨挂点，脱出的弹匣沿支撑手移动。 | 旁观者能看到角色持枪跑动、边跑边射和换弹。 |
| 跑停与停火需要确认 | 跑步状态按实际水平运动切换。持枪待命使用定格姿势并持续推进动画混合。 | 边跑边射后松开扳机恢复跑步，松开移动键后站定。原地停火后回到持枪待命，射击计数保持稳定，顶住墙时也恢复站姿。 |

截帧取自修正后的同机独立窗口。[第一人称拆弹匣](G4/viewmodel-reload.png) · [旁观者换弹](G2/soldier-reload.png) · [第三人称跑动射击](G4/soldier-running-fire.png) · [第三人称停火待命](G4/soldier-fire-released.png)
