# G2 仓库与骨骼

2026-11-22，Windows 10 x64，Godot 4.7.1 Compatibility，GTX 1050。模型与制作工具见 [资产清单](../资产清单与制作计划.md)。

```powershell
python -B tools/verify_godot_fps.py --suite arena --visible
```

房主和客人分别从各自出生区经调度室前门和侧门回到地面通道，随后走上各自的楼梯，到达 3.3 m 高走廊，沿直梯下降到底层，再反向攀爬并离开梯顶。两端验证了蹲伏状态，进程正常退出。物理由房主的 `CharacterBody3D` 驱动，探针通过鼠标方向和 WASD 走完整段路线。

首轮实际走到约 3.20 m 后，胶囊先与二层楼板的前沿相碰。调整斜坡碰撞同楼板的交接高度后，同一输入路径两侧均走通。可破坏箱体与固定掩体的真实阻挡复验见 [G3](G3.md)。

两个视角分别使用 50 骨第一人称蒙皮和 43 骨全身蒙皮。换弹用 Blender 5.1.2 拆分的步枪与弹匣，使用同一枪外观和两套队色。第一人称通过腕部目标解算持枪、移弹匣和投掷，远端使用导入片段和上半身骨骼覆盖。场景最后由 Godot 脚本装配，模型保留为可编辑的 Blender 文件。[Blender 源文件](../../../../examples/shiftline/assets/source/shiftline-kit.blend) · [二层走廊](G2/catwalk.png) · [双视角截帧](G4.md)
