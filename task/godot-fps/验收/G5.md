# G5 界面与恢复

2026-11-22，Windows 10 x64，Godot 4.7.1。编辑器 F5 进入大厅并用 WLAN 地址点击 Host，房间顶栏显示实际地址、端口、1/8 和队比分。

```powershell
python -B tools/verify_godot_fps.py --suite gameplay
```

Tab 打开人员表，含队伍、昵称、击杀、死亡和延迟。F1 在大厅、对局和结算切换当前界面。隐藏时准星一起消失，恢复后人员表保持原可见状态。隐藏时按 Esc 可显示房间菜单，释放鼠标。在菜单里发送点击事件，弹匣数量保持原值。再按 Esc 返回对局。客人在界面隐藏时也能接收房主退出提示并返回可操作大厅。
