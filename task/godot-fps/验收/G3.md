# G3 房主权威对局

2026-11-22，Windows 10 x64，Godot 4.7.1。正常大厅创建房间、加入、离房。剧本从进程的实际键鼠入口提交输入。为压缩复验时间，探针在房主安排交火站位和 29 分边界，其余生命值、发弹、命中、步枪伤害和胜负由正式规则处理。

```powershell
python -B tools/verify_godot_fps.py --suite gameplay
```

| 用例 | 实测 |
| --- | --- |
| V4 交火 | 客人击败房主，Ember 加 1 分，客人个人击杀加 1。房主复活后客人再次看到存活角色。同队射击时目标 HP 不变。 |
| V4 弹匣 | 连发耗完弹匣，按住射击时曳光计数保持稳定。换弹后弹匣为 30，备弹为 60，下一枪弹匣为 29。 |
| V5 争用、刷新 | 两端同时按 E，备弹总和只增加 45。手榴弹补给增加 1 枚。两种补给均按房主代次刷新。 |
| V5 晚加入、碰撞 | 第三端看到先前的比分、K/D、已用补给、碎箱和仍然飞行的手榴弹，并等到飞行物落地和爆炸。它从碎箱原位走过，随后被蓝色集装箱挡住。投掷者离房后，剩余飞行物正常引爆一次。之后重进的客人看到空的投掷物列表和零次爆炸回放。 |
| V6 胜负和第二局 | 将边界置于 29 分，以三次射击将对手打至 25 HP，两名同队客人同时开火。只产生第 30 分及一个胜方。结算期加入者看到同样结果。五个成员保持连接进入第二局，比分、K/D、库存、箱体、补给及投掷物恢复新局状态。 |

同机脚本同时读取房主、客人和晚加入端。探针在房主物理步记录 3 秒到期与新生命激活的差值。可视 WLAN 地址运行测得 0.16 ms，扩展的同机回环运行测得 16.52 ms，最终 WLAN 地址无界面复跑测得 0.03 ms。实测均在 60 Hz 下的一个物理步内，退出码均为 0。
