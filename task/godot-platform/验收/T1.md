# T1 · 原生节点与 Inspector

Godot 4.6.1 Windows x64，隔离工程载入原生 ClassDB 类型。抽象的 `NetcodeReplicator` 不可直接实例化，Shared 与 Spawner 可新建，并分别执行挂在原生节点上的业务脚本。运行时测试禁用编辑器插件。Shared 解析到父根节点，Spawner 默认生成路径为 `..`。

编辑器加载 SDK 后选中 Shared。底部字段面板从实际树中选择 `:trail`，向共享资源追加路径，容量设为 4。插值设置可撤销、重做、保存并绕过对象缓存重读。两个模板指向同一外部资源。编辑器和运行时用例均以断言与退出码验收。

复跑入口为 `python -B tools/verify_godot_native.py --addon <SDK ZIP>`。旧路径、UID 和迁移映射见[接入规格](../../../docs/specs/godot-scene-sync.md#旧场景迁移)。
